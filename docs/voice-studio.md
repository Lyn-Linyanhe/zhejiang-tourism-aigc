# 配音工作台

## 使用流程

1. 生成脚本预览，进入审核页的“声音”部分。各镜头旁白自动进入声音轨道。
2. 选择音色卡片，或沿用原来的八种音色选择框。卡片同时设置推荐语气。
3. 点击轨道片段，修改旁白、片段语气、语速倍率、音高偏移、镜后停顿。
4. 点击“试听选中片段”或“合成整轨试听”。试听使用当前未保存的文字与参数，只生成音频，不调用画面生成服务。结果显示实际引擎、音色和时长，可播放、下载 WAV。
5. 修改参数后旧试听会失效，需要重新生成。试听文件位于任务的 `voice-previews` 子目录，各次结果独立保存。
6. 保存草稿；“确认并生成实际视频”也会先保存当前编辑，再开始生成。

## 自然度处理

- 逗号、顿号不再切成独立合成请求；保留完整句子的上下文和模型生成的停连。
- 自然、温暖、人文、轻快语气使用确定性规则，对完整句子做小幅音高/语速调整，疑问和感叹句有不同参数。它不是情绪识别模型，也不是逐字基频编辑器。
- 强度 0 或“原声直读”关闭自动变化，用户的全局和局部手动设置仍生效。
- 不改变汉字音调的内部曲线，避免为模仿歌唱音符而破坏普通话声调。
- 字幕按实际合成句段时长同步。字幕与旁白句数不对应时保留整镜字幕，不伪造字级对齐。
- 时间轴合成前显示“分镜预估”，整轨试听后显示实测时间。参数栏是合成控制值，不是假造的声波或基频测量。
- 时长适配仍沿用最多 1.25 倍再合成策略；若试听仍超出目标，会提示缩短文本。上传音频不进行变速或变调。

## 内置声库与本地运行

四组联网快捷预设为晓晓、云希、云健、晓伊，原有八种 Edge 中文音色仍可选。另新增独立的“天依 · 本地声库”卡片，使用安装到本项目运行目录的社区模型进行文本合成。

“神经音色（联网）”使用 Edge TTS，明确选择后失败即报错。“Windows 系统语音（本地）”使用本机已安装的声音，只支持语速，不保证存在对应性别或神经音色，不支持这里的音高偏移。“跟随服务端配置”延续配置的降级策略，试听显示实际来源及降级提示。

音频运行时已固定 `edge-tts==7.3.1`；本机旧版 7.2.8 在验证时返回接口 403，更新后真实合成通过。安装脚本 `scripts/setup-edge-tts.ps1` 同步固定版本。

## 天依本地社区声库

选择“天依 · 本地声库”，填写或修改镜头旁白，直接点击单段或整轨试听；保存后视频生成沿用同一引擎。已绑定的导入音频仍优先使用，如需文本重新合成，先解除该片段音频绑定。

- 来源：[Kevin14827/LuoTianyi-TTS](https://github.com/Kevin14827/LuoTianyi-TTS)，模型 `tianyi2-e15.ckpt` / `tianyi2_e8_s128.pth`，基于 GPT-SoVITS v2Pro。它是社区训练的洛天依音色，**不是 X Studio 官方声库**；没有复制或调用 X Studio 私有模型。
- 当前接入面向中文旁白。句内语调由模型生成；自动语气规则仅应用语速，支持全局/局部语速与镜头间停顿。Hz 音高偏移对该引擎禁用，不将其显示成已生效的调音结果。
- 首次加载较慢；连续合成复用同一子进程，空闲 90 秒释放。单次请求上限 1,000 字、240 秒；缓存命中时直接复用真实音频。失败明确报错，不换成其他人物音色。
- 后端主环境不安装重依赖；独立使用 `.venv-tianyi`。模型、来源与校验记录位于 `runtime/tianyi/manifest.json`，推理日志为 `runtime/tianyi/inference.log`。运行时设置 Hugging Face / Transformers 离线模式。
- 上游代码声明 MIT；声库权重的完整商业使用授权未得到确认，本地原型不代表取得官方或商用授权。

首次安装（需要 Python 3.11、FFmpeg，下载期间联网）：

```powershell
powershell -File scripts/setup-tianyi.ps1
```

默认安装 CPU 运行时；可加 `-Cuda` 安装 PyTorch CUDA 12.4 版本（下载体积更大，需要兼容 NVIDIA 驱动）。安装脚本固定引擎/基础模型修订及天依权重 SHA-256，支持大文件分段续传。安装完成后刷新页面，卡片显示安装状态。模型不提交 Git；复制项目到另一台电脑时需重新安装或连同运行目录一起迁移。

Windows 适配：使用 `jieba` 兼容 `jieba_fast` 的分词接口，参考音频由 FFmpeg 直接解码，避免导入上游 Gradio 训练界面。语言检测使用依赖中自带的小模型，英文发音词典随首次安装下载。上游引擎源码保留原样，适配只在隔离的推理子进程内生效。

## 上传配音音频

工作台保留通用的“上传配音音频”入口，不再显示 X Studio 专属卡片或来源选项。

1. 点击“上传配音音频”卡片，进入上传模式并定位到上传区域。
2. 选择镜头和录音或已制作的音频文件，点击“上传配音”。
3. 上传模式需为每个镜头绑定音频；缺失时明确提示补齐，不会自动换成合成音色。
4. 如果只想替换个别镜头，可保持天依等合成来源，直接在上传区域绑定音频；其余镜头继续由所选模型合成。

上传音频保留原有音高与语速，可试听、解绑或用于最终成片。来源记录为 `local-upload`。旧草稿中的 `xstudio` 来源兼容映射为 `upload`，已有音频绑定继续保留；保存后使用新的通用来源名。

## 接口

- `POST /api/tasks/{id}/voice-plan`：接收 `input` 和 `shots` 当前编辑快照，返回规则规划，不修改任务。
- `POST /api/tasks/{id}/voice-preview`：同上，可加 `shot_id` 试听单段。返回实际音频 URL、实测轨道和 provider trace。
- `PATCH /api/tasks/{id}/shots/{shot_id}`：保存片段 `voice_style`、`voice_rate_scale`、`voice_pitch_offset`、`voice_pause_after`；`clear_audio: true` 解除已有音频绑定。
