# 2026 年 11 月 21 日项目更新

本次更新适用于 Windows 源码运行。安装 Python 后通过根目录的 `START.cmd` 启动。本机服务凭据通过 `.env.example` 配置为本地 `.env`。

## 11 月 21 日的项目调整

| 模块 | 调整内容 |
| --- | --- |
| 文旅知识库 | 补齐浙江 11 个设区市的代表性条目，现有 103 个实体、335 条事实。新增条目含来源链接、画面提示与素材检索词。脚本和素材检索按城市匹配。 |
| 分镜素材 | 在线实拍素材检索保留原始素材页、作者、许可和地点线索。图生视频支持主体组参考图。上传图片和视频可填写来源、授权方、条款、用途及凭证。 |
| 配音工作台 | 支持音色选择、整轨或单段试听、语气和语速等调整，以及逐镜上传配音。语音按完整句子合成，字幕按实测句段计时。新成片的音频链路统一为 48 kHz 立体声。 |
| 配乐与授权 | 在原电脑交付中，18 首自备曲目按上传者声明入账。源码首次运行时可通过曲库导入界面添加曲目。导入可补填作者、使用范围和凭证。实际使用的曲目随任务存档。 |
| 成片核验 | 按镜从成片抽取前、中、后段画面，检查缺帧与近黑，结合分镜和来源保存结论。核验绑定成片 SHA-256，保留结论记录。 |
| 任务及费用台账 | 可导出脚本、分镜、素材和授权、配音、渲染、核验及调用记录。按币种汇总已对账金额。缺供应商凭证的条目标记为待对账。 |

## 核验记录

- 知识库覆盖 11 市。独立的宁波 15 秒竖屏流程已验证脚本、分镜、配音、配乐、烧录字幕、逐镜抽帧及底账下载。
- 历史作品曾复核 6 条成片、34 镜和 102 张抽帧。部分旧素材缺少可核验地标，有三条历史作品为横屏。源码首次运行会新建本地档案。
- 实际费用以供应商账单为依据。作品档案保留待对账状态，并支持按调用录入金额与凭证。
