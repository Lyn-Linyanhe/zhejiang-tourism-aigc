## 画面规律

### 兰亭

- 高频画面：入口/门楼正面、鹅池碑亭、兰亭碑亭、曲水流觞、竹林、白鹅、书法幡旗。
- 构图：对称正面、低机位、石阶或水面做引导线；碑刻/匾额用局部特写。
- 风格：国风、古建、青绿、高饱和；部分笔记用**手绘路线图 + 编号机位**，比纯照片更适合做脚本结构参考。
- 旅行角度：上午人少、竹林光影、曲水边坐一会儿、书法博物馆；笔记里常提“半天/3–4 小时”。
- 待核说法：门票 70 元、开放 8:00–16:40、“康熙御笔”“王羲之父子合璧”“7 个拍照机位”。

### 东湖

- 高频画面：采石崖壁、绿色湖水、乌篷船、陶公洞/仙桃洞、石桥。
- 构图：**竖构图**强调崖壁高度；船作为尺度参照；水面/水道做引导线；洞口做框景。
- 风格：青绿、水墨、清透；阴天也能拍出层次。
- 旅行角度：坐乌篷船穿洞、慢逛、避开热门景点人流；“天下第一水石盆景”是高频标签。
- 待核说法：“天下第一水石盆景”、三大岩洞名称、《西游记》女儿国取景地。

### 安昌古镇

- 高频画面：黄昏/夜晚河巷、白墙黛瓦、红灯笼、倒影、客栈木构、清晨街市、腊味/梅干菜/黄酒咖啡。
- 构图：河道透视线、低照度暖灯与冷天光对比、倒影；住一晚可拍“游客散去后的本地生活”。
- 风格：黄昏暖调、烟火气、低饱和。
- 旅行角度：住一晚看夜景、清晨逛老街、坐乌篷船、吃腊肠/梅干菜、喝黄酒咖啡。
- 待核说法：古镇免费、小景点联票 50 元、客栈原为钱庄、天官第/戏台位置、最佳时间。

### 仓桥直街

- 高频画面：屋顶瓦片、灯笼、巷弄、臭豆腐摊、河边茶座、原住民生活。
- 构图：屋顶高机位、层层瓦面、暖光点状、巷弄纵深。
- 风格：暖调、市井、烟火气。
- 旅行角度：不是“搬空的假古镇”，看原住民生活；钻小巷、河边喝茶、吃本地小吃。
- 待核说法：原住民户数、臭豆腐店铺、河边茶座位置、历史街区保护奖项。

### 鲁迅故里·沈园

- 高频画面：德寿堂、白墙黑瓦、鲁迅壁画、河道、三味书屋、鲁迅故里照壁。
- 构图：九宫格拼图、正面平视、局部特写、对称；课本打卡感强。
- 风格：纪实、课本感、黑白灰+木色。
- 旅行角度：从百草园到三味书屋、祖居/故居/风情园/纪念馆、免费预约、南门出来就是步行街。
- 待核说法：免费、公众号预约、各宅院名称与开放范围。

### 大禹陵

- 高频画面：石牌坊、神道、石炮、禹庙、碑刻、祭祀空间。
- 构图：中轴对称、神道引导线、正面低机位、建筑全景。
- 风格：纪实、古建、庄重。
- 旅行角度：祭祀传统、神道仪式感、禹庙/禹祠/禹陵、谷雨祭典。
- 待核说法：牌坊 1995 年、禹庙始建于 545 年、现存大殿 1933 年、大禹陵碑 1540 年、1956 年台风、2006 年国家级非遗、谷雨上午 9 点。

## 可复用的“旅行角度卡”

这些是脚本/分镜可用的角度，不是事实结论：

1. **兰亭**：手绘路线图开场 → 鹅池碑亭 → 曲水流觞 → 书法幡旗/竹林空镜。
2. **东湖**：竖构图崖壁建立空间 → 乌篷船穿洞 → 水面倒影 → 洞口“一线天”。
3. **安昌**：黄昏灯笼亮起 → 河道倒影 → 清晨游客未至 → 腊味/黄酒咖啡特写。
4. **仓桥**：屋顶高机位建立老城肌理 → 巷弄纵深 → 臭豆腐摊/河边茶座 → 原住民生活细节。
5. **鲁迅故里**：课本封面式开场 → 德寿堂/三味书屋 → 百草园 → 鲁迅故里照壁收尾。
6. **大禹陵**：石牌坊中轴 → 神道纵深 → 禹庙殿宇 → 碑刻/祭祀细节。
