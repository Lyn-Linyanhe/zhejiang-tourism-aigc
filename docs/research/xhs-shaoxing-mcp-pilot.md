## 镜头意图映射

上面六段是“一条片子的顺序”，映射文件则把它拆成可检索的条目：**29 条、6 个景点、14 列**，其中 25 条是画面镜头、4 条是叙事/预期管理；置信度 high 16、medium 12、low 1。

- 每条含 `shot_tag`（establishing/landmark/detail/water/boat/people/food/night/season/overlook/interior/transition/route/light/context）、`intent`（镜头意图）、`motif`、`composition`、`best_window`、`confidence`。
- `support_note_ids` 指向 62 条笔记里的具体 ID，`support_count` 是支撑条数；脚本生成时可只取 high，medium 作备选。
- `claim_risk` 只记录“这条角度涉及的待核说法”（票价、开放时间、年代、取景地等），不把说法升级成事实。

两个必须知道的缺口：

1. **东湖不在知识库**：`sx-donghu` 标了 `in_kb=false`。东湖是试点 6 景点之一，但 `data_zhejiang_kb/shaoxing.json` 目前没有这个实体。要用它的镜头卡，得先补实体、事实和来源；否则脚本阶段应过滤掉 `in_kb=false`。
2. **只覆盖 5 个知识库实体**：黄酒、越剧、莲花落、乌篷船制作技艺、古香榧群没有可用的 XHS 画面材料。乌篷船笔记拍的是“坐船”，不是“造船”，不能拿来充当制作技艺的画面。

三个非遗实体（黄酒/越剧/莲花落）如果要补镜头，方向应是工坊/舞台/传习所，而不是景区游客照；这轮没有采集，不要用其他画面冒充。

## 许可与合规

- 小红书笔记的**文字、图片、视频版权归作者/权利人**。本轮只通过 MCP 读取元数据和 300 字以内描述摘要，**没有下载原图、没有复制完整正文、没有把图片写入素材库或提交仓库**。
- 所有记录为 `reference-only`；不得直接作为成片素材、知识库 facts 或发布素材。
- 需要实际图片时：取得作者书面授权，或换成 Wikimedia Commons / Pexels / 官方授权图 / 团队自摄。
- MCP cookies、xsec_token 属于敏感会话信息，不写入仓库；token 可能过期，note_id 稳定。
- 本轮为登录后只读浏览，没有批量抓取、没有绕过登录、没有使用第三方镜像。

## 局限

1. 只覆盖 6 个景点，每处 12 条；不是绍兴全量。
2. MCP 的 `note_type=图文` 和 `publish_time=半年内` 过滤不严格：混入 7 条视频/单图、7 条旧笔记；已在 CSV 标记，未静默删除。
3. 点赞/收藏未归一化，搜索排序有热度与商业推广偏差。
4. MCP 数据是元数据 + 描述摘要，**没有逐张看图**；画面判断来自人工试点的 7 条代表笔记 + 标题/摘要母题，不能替代完整图集目视。
5. 部分笔记是“绍兴多景点一日游”，目标景点只是其中一站；已用 `spot_mentioned` 与 `usable_for_visual_reference` 标记。
