# 浙江文旅知识库数据源调查

> 调查日期：2026-11-19
> 范围：浙江及国家级官方目录、开放知识图谱/地名数据、地图和旅游平台 API、学术地理数据。
> 结论性质：桌面来源调查，不是法律意见；“页面可看/接口可调”不等于“获准批量导入、缓存、商用或再分发”。本次未登录、未调用需 Key 的 API、未批量下载数据，也未把候选数据写入知识库。

## 结论摘要

1. **未找到经核实、单一且公开许可明确的“浙江 11 市全量文旅实体及事实”可直接导入数据库。**可用方案更可能是多源组合：开放许可的基础实体/别名/地名数据 + 按主管事项发布的官方名录与公告 + 人工事实审校。
2. **优先许可候选：Wikidata 结构化数据（CC0）和 GeoNames（CC BY 4.0）。**适合补充实体标识、名称/别名、类别、地理关系与候选坐标；并非景点史实、非遗事实、景区等级或城市文化叙事的权威证明。GeoNames 组件存在上游许可例外，应逐项核查并保留署名。
3. **浙江省“浙江·数据开放”门户值得优先逐条筛选。**官方门户列出 11 个设区市目录，并在每条数据上区分“无条件开放/受限开放”。平台协议允许免费获取其公共数据并非排他使用，要求标明平台来源和下载日期、说明应用性质、不得歪曲；数据被下线时须停止保存/使用。协议不能替代具体数据目录的开放属性和数据项限制。当前未核实清楚旅游名录的数据下载/API 和再利用细节，需把门户当作来源目录，不可自动全站采集。
4. **文旅部官方 5A 景区目录是核对等级/评定年份的好入口，不是通用景点库。**页面结构化显示 358 条记录，字段为景区名、地区、A级、评定年份；页面用内部接口呈现，但未核实该接口为公开数据 API，也未找到允许批量复制或再分发的特定许可。
5. **国家级非遗查询可按浙江省、批次、类别、类型筛选，适合查正式项目名录；但中国非遗网版权声明对商业使用/改写有明确限制。**应作为事实核验入口，不得在未获书面授权时批量复制其项目介绍进入商业知识库。
6. 高德、百度、腾讯地图是受服务条款约束的在线查询产品；携程/去哪儿属平台合作接口，不是公共可再分发 POI 库。**不要把 API 查询结果默认长期存入知识库。**
7. 政府/学术资料的“权威性”与“再利用许可”分开处理。国家图书馆、国家哲社文献中心、学术历史 GIS 适合作人工查证或限定研究；有的明确禁止批量下载或商业再分发。

### 浙江及地方政府

1. **浙江·数据开放平台**：<https://data.zjzwfw.gov.cn/>。主页显示“浙江·数据开放”；`https://data.zjzwfw.gov.cn/dopServer/#/dataCatalogIndex` 的目录页显示数据领域、开放属性和按数据名称/摘要/数据项搜索。页面显示 11 个设区市目录，逐市计数为杭州 3,716、宁波 2,090、温州 2,024、嘉兴 1,542、湖州 1,307、绍兴 1,823、金华 2,272、衢州 1,582、舟山 868、台州 1,697、丽水 1,023（为门户目录资源数，不是文旅资源数）。目录搜索“旅游”“旅游景点信息”时，页面给出旅游景点、景点图片、景点门票、临安/文成/仙居/余杭/上虞等子目录题名；搜索状态与结果列表在本次浏览中异步更新不完全一致，所以这些名称仅作门户检索发现，**尚未核实具体条目的完整元数据/文件下载**。

### 国家级官方名录与文化资料

4. **文化和旅游部旅游名录查询**：<https://lyfw.mct.gov.cn/site/special/scenic>；浏览器内实际进入 <https://www.mct.gov.cn/tourism/#/list?drid=4>，显示“5A级旅游景区”全国列表、字段“景区名称/地区/A级/评定年份”、358 条。侧栏还列红色旅游景区、全国乡村旅游重点村镇、国家级旅游度假区、国家级旅游休闲街区、国家级滑雪度假地、工业旅游示范基地、星级饭店和旅游民宿等查询栏目。文旅部页面是主管部门名录查询，适合核对被认定/评定事项；内部 `/tourism/api` 路径未视为公开 API，页面没有核实到可下载全量文件或批量复用许可。省/市、批次等需按页面筛选或正式公告核对。
5. **中国非物质文化遗产网·代表性项目名录**：<https://www.ihchina.cn/project.html>；页面提供省份、批次、类别、项目类型、项目名称筛选，可选浙江（省份代码 330000）。**版权声明/版权保护页需按其站点实际条款逐项确认**；本轮代理研究反馈其声明限制未经书面许可的商业使用/改写，并要求标注作者及来源。因此建议只取正式项目名、类别、批次等必要核验事实，并保存目录页/批次公告链接；不复制项目介绍或批量抓取内容，直至得到许可。
6. **文化和旅游部及国家文物/文化机构公告**：用于核实 A 级景区、旅游度假区/街区、乡村旅游重点村镇、博物馆、非遗批次、历史文化名城及文保单位等具体主管事项。逐次以部委官网公告/正式附件为事实来源。本次有些国家文物局历史公告链接因 404/站点访问限制未完成可用性核验，故不宣称已找到全国可批量下载的统一名录 API。
7. **国家图书馆/国家方志与文献平台**：<https://www.nlc.cn/> 可作为馆藏和地方志检索入口；**国家哲学社会科学文献中心**：<https://www.ncpssd.cn/>。代理研究核到 NCPSSD 条款不允许连续/系统/批量下载、商业服务或汇编二次产品，故仅作人工检索线索；各家数字方志权限要看具体资源许可。
8. **UNESCO 世界遗产/非遗名录**：<https://whc.unesco.org/en/list/>、<https://ich.unesco.org/en/lists> 是相应公约名录来源。代理研究称本次浏览遇访问防护，未绕过；需后续直接检查站点许可、数据下载/API 及复用条款，不能将 UNESCO 标识当成开放再分发许可。

### 可开放知识图谱与地理数据

9. **Wikidata**：[Copyright](https://www.wikidata.org/wiki/Wikidata:Copyright)、[Licensing](https://www.wikidata.org/wiki/Wikidata:Licensing)、[Data access](https://www.wikidata.org/wiki/Wikidata:Data_access)。结构化主数据采用 CC0，可作为景点/人物/城市实体 ID、名称与别名、类别、坐标、行政关系、外部标识符的候选补充。不同命名空间/文本不当然属于 CC0；逐条实体仍需权威资料复核。
10. **GeoNames**：[About](https://www.geonames.org/about.html)、[Web Services](https://www.geonames.org/export/web-services.html)、[Credits](https://www.geonames.org/export/credits.html)、[Commercial Web Services](https://www.geonames.org/commercial-webservices.html)。官方说明约 3,200 万地名、1,300 万地理实体，许可 CC BY 4.0；须署名，个别数据保留其自身版权。免费 Web Services 需用户名和积分额度；商业/可用性更高的付费档要按官网价格页确认。适合地名/层级/坐标辅助，非文旅史实权威源。
11. **OpenStreetMap**：[版权](https://www.openstreetmap.org/copyright)、[Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/)、[Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)。数据为 ODbL；须署名并评估衍生数据库的相同方式共享义务。公共 Nominatim 有不超过 1 req/s、缓存等规则，不适合批量生产采集；标准瓦片亦禁止预取/离线批量下载。若选用，应使用许可合规的数据分发或自建实例，而不是把公共服务当采集 API。
12. **DBpedia**：[Resources](https://www.dbpedia.org/resources/)、[SPARQL](https://www.dbpedia.org/resources/sparql/)、[Databus](https://www.dbpedia.org/resources/databus/)。可查询/下载抽取数据，但资源总页没有证明全部数据集都享同一许可；逐数据集核对元数据及维基来源授权。
13. **中文维基百科/Wikimedia**：[MediaWiki API data formats](https://www.mediawiki.org/wiki/API:Data_formats)、[Terms of Use](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use)。百科正文通常按 CC BY-SA/GFDL 体系使用，许可义务及图片等第三方素材要逐页核对；适合发现线索，避免直接搬整段正文。
14. **CHGIS V6**：[项目数据页](https://chgis.fas.harvard.edu/data/chgis/v6/)、[Harvard Dataverse](https://dataverse.harvard.edu/dataverse/chgis_v6)。历史地名和行政区划可能适用于历史地理核验；代理研究指出其为学术研究用途，禁止商业使用/转售/再分发，不能用作商业知识库底库。

## 推荐组合与筛选规则

### 首选组合

- **实体骨架：** Wikidata CC0 + GeoNames CC BY 4.0（署名、核上游例外）补充规范化名称、别名/多语言标签、外部 ID、地名层级和候选坐标。仅将它们作为“实体匹配和发现层”。
- **官方事实层：** 按主题从浙江平台的明确“无条件开放”数据集、文旅部/省市主管部门正式名录和公告取必要字段。对每个数据集记录其许可、来源机构、数据资源编码、版本/下载日、更新频率；受限开放须单独审批，未核许可的页面只供人工事实核验。
- **历史/地方志层：** 仅在具体资源许可容许时录入经核实的短事实，并保存原始出处。不将 CHGIS/NCPSSD/维基百科长文本或授权受限数据库批量移入商业库。
- **地图 POI 在线服务：** 高德/百度/腾讯只用于明确获许可的在线展示或用户发起的查询；默认不存储结果、不再分发。若目标必须本地持有 POI，优先谈书面数据许可，或评估 OSM ODbL 自建数据方案。

### 浙江平台条目入选门槛

1. 详情页必须显示“无条件开放”；不得从分类名或搜索摘要推断许可。
2. 核验元数据、具体数据项、个人/敏感信息剔除说明、更新频率、下载/API 方式、调用配额及数据下线机制。
3. 读取该条适用许可及平台现行协议；确认商用、再分发、缓存、生成内容发布、署名/下载日期义务。不得为绕过登录或受限许可进行爬取。
4. 记录资源编码及下载日期；运行增量更新前复查下线状态。数据字段入库前由人工抽查权威性和行政归属。

## 到现有知识库的映射建议

当前模式见 `data_zhejiang_kb/_meta.json` 与 `hangzhou.json`：文件级 `city`、`city_meta`，实体含 `id/type/name/aliases/location/facts/cultural_significance/keywords_en/imagery/best_season/micro_drama_hook/scenario_tags`。当前 `facts` 为字符串数组，**不要直接把它改为对象数组**，会破坏 prompt 渲染兼容性。

建议先为实体增加可选来源集合，为结构化事实引入新字段并暂时保留兼容字符串 `facts`：

```json
{
  "id": "ningbo_tianyige",
  "city": "宁波",
  "name": "天一阁",
  "aliases": ["天一阁博物院"],
  "location": "宁波市海曙区",
  "facts": ["……（已核查的短事实，保留兼容）"],
  "fact_records": [
    {
      "text": "……",
      "source_url": "https://official.example/source",
      "source_title": "主管部门名录/公告标题",
      "source_publisher": "发布机构",
      "source_id": "数据资源编码或公告编号",
      "retrieved_at": "YYYY-MM-DD",
      "checked_at": "YYYY-MM-DD",
      "valid_until": null,
      "license_id": "具体数据集许可标识",
      "license_url": "https://...",
      "fact_type": "designation|history|location|intangible_heritage|event"
    }
  ],
  "external_ids": {"wikidata": "Q...", "geonames": "..."},
  "coordinates": {"lat": 0.0, "lon": 0.0, "crs": "WGS84", "source_url": "..."}
}
```

以上是结构设计建议，不是本轮已实现 schema。坐标系、城市归属语义要明确区分“行政所在地/发源地/传承地/文化关联地”；活动日期、票价、开放状态应放在独立的时效信息模型，必须带 `valid_from/valid_until/last_checked_at`，不可塞进永久 facts。

## 城市覆盖与试点建议

门户在目录层面覆盖 11 市，但目录资源总数不代表文旅数据覆盖。当前项目知识文件已有杭州样板和宁波 9 条非遗试点记录；宁波仍只覆盖 `intangible` 类，不代表宁波全量文旅覆盖。推荐第一轮选**宁波（天一阁 + 一项宁波非遗 + 一个官方景区等级记录）**作为 schema/来源试点：

- 天一阁：核对文旅主管部门/博物馆官方介绍和浙江省开放目录条目是否可合法复用；当前已核实到宁波文广旅局官方文章，但尚未将叙述性文章复制进知识库。
- 非遗：宁波非遗保护中心在线名录已采集 9 个短目录事实（项目名、国家级级别、批次、门类、地区），每条绑定详情 URL；站点未发现明确开放再分发许可，均标为 `fact-only-pending-license-review`，不得宣称已获商用授权。
- 景区等级：文旅部名录仅录入景区名、行政地区、等级、评定年份，并保留目录/公告出处；宁波 5A 查询结果尚未完成稳定的筛选/导入，因此不计入当前采集量。
- 外部标识与别名：Wikidata/GeoNames 只作匹配候选，手工确认后记录 external id 和许可证；本轮未把它们批量写入宁波数据。
- 每类先导入少量 5–10 个实体，做人工事实核验与现有知识检索/英文查询回归，再决定规模化补齐。

试点验收标准建议：每条可生成事实都有可回到原文的一手证据；每个实体行政归属/起源/传承语义无混淆；城市过滤与同名实体无跨城污染；授权状态不明的描述不得标成“已核查/批准发布”。

## 调查限制与未决项

- 浙江门户目录列表可见，但本轮没有完成旅游条目详细页、实际下载文件/API、单个资源许可全文及数据质量抽样；搜索摘要不作为实证。
- 文旅部公开 5A 名录页面内有列表字段和 358 条计数；内嵌 API 的公开使用条件、批量/再分发许可未核实。
- 非遗网省份筛选页可见；其版权声明需要在实际数据接入前再次逐字核查并取得必要许可。国家级保护单位与地方志资料的机器可读覆盖尚未完成全面摸排。
- 11 市分项目录统计来自门户 UI（检索日期 2026-11-19）；不是旅游实体数量，也可能随平台变动。
- Wikidata、GeoNames、OSM 对目标城市的实际匹配率/缺字段比例需以小样本试查和许可合规数据下载实测，不可把全球规模等同于本地高质量覆盖。
- 本报告不是商用法律意见；对条款有歧义、受限开放数据、地图商用响应数据，应请数据提供方书面确认许可范围。
