TEXT

DeepSeek 做什么

根据城市、主题、文化线索、受众和补充要求生成标题、旁白、分镜画面描述和字幕。API key 只在后端环境变量中读取。

MEDIA

画面与音频

可使用每镜头上传的图片/视频、Pexels 图片或明确标记的技术场景图。配音优先使用外部 TTS、Edge TTS 或 Windows 系统语音，音乐使用上传文件或本地音乐库。

DELIVERY

最终交付

渲染器输出 MP4、SRT、封面、音频和 manifest。没有音频、字幕或真实素材时，任务会显示实际状态，不会生成虚假的成功结果。
